# smart-resume-scorer

A Java-based ATS-inspired Resume Screening and Ranking System developed using Java Swing and Apache PDFBox.

## Features

* Resume Parsing from PDF Files
* Automatic Candidate Scoring
* Skill Matching
* Resume Ranking
* Candidate Shortlisting
* Interactive GUI

## Technologies Used

* Java
* Java Swing
* Apache PDFBox

## Concepts Used

* Data Structures & Algorithms
* Sorting
* Hashing
* Greedy Techniques

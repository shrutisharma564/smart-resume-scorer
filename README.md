# 🚀 Smart Resume Scorer

An ATS-inspired Resume Screening and Candidate Ranking System built using Java Swing, MySQL, JDBC and Apache PDFBox.

The application automates resume evaluation by parsing PDF resumes, matching candidate skills, calculating ATS scores, ranking applicants, maintaining evaluation history and exporting reports.

---

# ✨ Features

- Secure User Login & Registration
- SHA-256 Password Hashing
- Resume Parsing using Apache PDFBox
- ATS-style Resume Scoring
- Skill Matching using HashSet
- Candidate Ranking
- Resume Shortlisting
- Evaluation History
- Export Reports to CSV
- Export Reports to PDF
- Interactive Java Swing GUI
- MySQL Database Integration

# ⚙️ Installation

1. Clone the repository

```
git clone https://github.com/shrutisharma564/smart-resume-scorer.git
```

2. Open the project in IntelliJ IDEA or VS Code

3. Install MySQL

4. Execute

```
sql/schema.sql
```

5. Update

```
db.properties
```

6. Run

```
Main.java
```
